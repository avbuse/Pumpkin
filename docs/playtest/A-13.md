# A-13 playtest: axe strip, shovel path, and hoe till

Use a survival player in a new overworld. Each step starts with the tool in the main hand and the target block within reach. Durability is the damage number on the tool.

1. Right-click an oak log with an axe. Repeat on oak wood, and on a log whose axis is sideways.
   Expect a stripped oak log or stripped oak wood. The sideways log stays sideways. The axe takes 1 durability. You hear the strip sound.

2. Right-click exposed copper, oxidized copper, and a waxed copper block with an axe.
   Expect exposed copper to become a copper block, oxidized copper to become weathered copper (one stage, not all the way back), and the waxed block to become an unwaxed copper block of the same stage. Scrape and wax-off use their own sounds and particles. Each use costs 1 durability.

3. Right-click one half of a copper door and one half of a double oxidized copper chest that has items inside.
   Expect both door halves to change together and keep facing, open, and hinge. Expect both chest halves to drop one oxidation stage together. The items are still in the chest. `/setblock` of one copper-chest half to another copper chest also changes the connected half and leaves that half's items in place.

4. Right-click a grass block with a shovel, with air, cave air, or void air above it.
   Expect a dirt path, the flatten sound, and 1 durability. The same click on the bottom face does nothing. A grass block with stone, water, or a flower above it stays grass.

5. Right-click dirt and grass with a hoe, with air above, from the top or a side.
   Expect farmland with moisture 0, the till sound, and 1 durability. The bottom face does nothing. Dirt with a solid block or water above it stays dirt. Coarse dirt with air above becomes dirt, not farmland. Rooted dirt becomes dirt from any face, including underneath, and drops hanging roots even when a block is above it.

6. Hold a stick and right-click an oak log, a grass block, and dirt.
   Expect no change and no durability, because a stick is not a tool.

7. Switch to adventure (`/gamemode adventure`) and right-click an oak log, grass, and dirt with an axe, shovel, and hoe.
   Expect no strip, path, or farmland. Switch back is not required for the next step.

8. In adventure, right-click a lit campfire with a shovel.
   Expect the campfire to go out. That click is the campfire's own action, so adventure still allows it. A shield in the off hand does not stop it either.

9. In creative, right-click an oak log with an axe.
   Expect the log to strip and the axe to keep full durability.

10. Hold an axe, shovel, or hoe in the main hand and a shield in the off hand. Right-click a log, grass, and dirt without sneaking.
    Expect no strip, path, or till. Sneak and right-click the same blocks.
    Expect the blocks to change. Using the tool from the off hand, with the shield still in the off hand, is not this case: the shield check only applies to the main hand.

## Extra scope

The task named logs, paths, and farmland. This branch also does two things the data tables require:

- Copper doors are rewritten as a pair. Both halves keep their properties. The door's placement callback is skipped, so clicking the upper half does not write a new door into the block above it.
- Copper chests, including waxed chests, scrape and dewax. A double chest's other half is not written by the axe. It follows the copper chest neighbour update, which is also what `/setblock` runs. The chest block entity stays when one copper chest replaces another, so the items stay in both halves.

## Automated checks

These live in `crates/pumpkin-data/src/block_transformer_tests.rs` and `crates/pumpkin-core`. They do not boot a world.

| Check | Expected |
| --- | --- |
| Oak log with axis `x` | Stripped oak log, axis `x`, strip sound, 1 durability |
| Exposed copper | Copper block, scrape sound and particles |
| Oxidized copper | Weathered copper, one stage |
| Waxed oxidized copper | Oxidized copper, wax-off sound and particles |
| Exposed copper door, upper half, facing west, open | Copper door with those properties kept |
| Grass with air or cave air above, clicked from above | Dirt path, flatten sound, 1 durability |
| Grass with stone or water above, or clicked from below | No path |
| Dirt or grass with air above, not from below | Farmland, moisture 0, till sound, 1 durability |
| Dirt with stone above, or clicked from below | No farmland |
| Coarse dirt with air above | Dirt, not farmland. Stone above blocks it |
| Rooted dirt from below with stone above | Dirt, loot `minecraft:till/rooted_dirt`, drop from the clicked face |
| Stick item id | Not in the axe, shovel, or hoe tags. Stone does not transform |
| Main hand, off hand blocks attacks, not sneaking | Tool use passes |
| Sneaking, off-hand use, or no shield | Tool use does not pass for that reason |
| Shield item | Has `blocks_attacks`. A stick does not |
| Double copper chest, left half facing north, neighbour to the east | That half becomes the neighbour's copper chest and keeps facing and type |
| Same chest, neighbour to the west, a single chest, or a stone neighbour | The half stays as it is |

`cargo test -p pumpkin-data --lib block_transformer_tests` runs the transformer table. `cargo test -p pumpkin-core --lib item::items::tests` and `cargo test -p pumpkin-core --lib block::blocks::chests::tests` run the shield and chest checks.

Not covered by those tests:

- Adventure mode refuses strip, path, and till because `mayBuild` is false. A shovel still puts out a lit campfire.
- Creative pays no durability.
- A copper door's other half changes with the clicked half.
- A double copper chest changes both halves through the neighbour update, including after `/setblock`, and keeps its items.
- The rooted-dirt loot table actually spawns a hanging-roots item.
- A real client hears the sound, shows the particles, and raises the shield instead of using the tool.
