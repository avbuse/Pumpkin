# A-42 playtest

Predicates load from datapacks and from the vanilla files compiled into the server. Story advancements do not grant in this task. Block drops do not consult the loaded predicates yet.

## Checklist

1. Start a debug server in an empty directory and wait for the done line.
2. Expect a log line that skips `minecraft:block/fast_cooking` because its type is `minecraft:match_block`. Expect another line that two embedded predicates loaded. The server should stay up, with no panic.
3. Add a datapack named `predicate_check` and enable it. Give it these files:
   - `data/test/predicate/shears.json`, copied from the vanilla `tool/can_shear` predicate (`minecraft:match_tool` for `minecraft:shears`).
   - `data/test/predicate/unknown.json` containing `{ "type": "minecraft:not_a_real_predicate" }`.
   - `pack.mcmeta` with a current pack format.
4. Run `reload` from the console.
5. Expect a log line that skips `test:unknown` with unknown type `minecraft:not_a_real_predicate`. Expect the pack's recipe and loot counts, if you also added those files, to be unchanged from a pack that has no predicates. The server should not panic.
6. Join with a client. Break glass with a normal pickaxe and with Silk Touch. Both results match the current server: the silk-touch predicate is loaded, and drops do not use it yet.
7. Pick up a crafting table. `story/root` does not grant yet. That is A-43 and A-44.

Capture: the console after boot and after `reload`, showing the unknown-type lines and no panic.
