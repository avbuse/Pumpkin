# A-42 playtest

Predicates load as loot conditions. `get_predicate` returns one. A-43 and A-44 are the callers: story advancements resolve predicate ids there. This task does not grant advancements, and block drops do not call `get_predicate`.

## Checklist

1. Start a debug server in an empty directory and wait for the done line.
2. Expect an info line that three embedded predicates loaded. Do not expect a warning that skips `minecraft:block/fast_cooking`. The server should stay up, with no panic.
3. Add a datapack named `predicate_check` and enable it. Give it these files:
   - `data/test/predicate/shears.json`, copied from the vanilla `tool/can_shear` predicate (`minecraft:match_tool` for `minecraft:shears`).
   - `data/test/predicate/unknown.json` containing `{ "type": "minecraft:not_a_real_predicate" }`.
   - `data/test/predicates/ignored.json`, the same shears predicate under the plural directory. That directory is not loaded.
   - `pack.mcmeta` with a current pack format.
4. Run `reload` from the console.
5. Expect a log line that skips `test:unknown` with unknown type `minecraft:not_a_real_predicate`. Do not expect a line for `test:ignored` or for `minecraft:block/fast_cooking`. The server should not panic.
6. Join with a client. Break glass with a normal pickaxe and with Silk Touch. Both results match the current server. The silk-touch predicate is loaded, and drops do not call `get_predicate` yet.
7. Pick up a crafting table. `story/root` does not grant yet. A-43 and A-44 call `get_predicate` for advancements.

Capture: the console after boot and after `reload`, showing the three embedded predicates, the unknown-type line, and no panic.
