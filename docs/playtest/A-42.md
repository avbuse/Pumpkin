# A-42 playtest

Predicates load as loot conditions. `get_predicate` returns one. A-43 and A-44 are the callers: story advancements resolve predicate ids there. This task does not grant advancements, and block drops do not call `get_predicate`.

## Checklist

1. Start a debug server in an empty directory and wait for `Started server; took`.
2. Expect an info line `Loaded 3 embedded predicate(s)`. Do not expect a warning that skips `minecraft:block/fast_cooking`. The server should stay up, with no panic. `Loaded 3 embedded test instance(s)` is a different line and is already on core.
3. Stop the server. Add `world/datapacks/predicate_check/` with:
   - `pack.mcmeta` containing `{ "pack": { "description": "predicate check", "pack_format": 107 } }`.
   - `data/test/predicate/shears.json`, copied from `assets/datapack/data/minecraft/predicate/tool/can_shear.json` (`minecraft:match_tool` for `minecraft:shears`).
   - `data/test/predicate/unknown.json` containing `{ "type": "minecraft:not_a_real_predicate" }`.
   - `data/test/predicates/ignored.json`, the same shears predicate under the plural directory. That directory is not loaded.
4. Start again. From the console run `datapack enable "file/predicate_check"`, then `reload`. If enable says the pack is unknown, `datapack list` and use the printed name.
5. Expect `Skipping predicate 'test:unknown': unknown type 'minecraft:not_a_real_predicate'`. Do not expect a line for `test:ignored` or for `minecraft:block/fast_cooking`. The server should not panic. The datapack load line for `predicate_check` includes a predicate count.
6. Join with a client. Break glass with a normal pickaxe and with Silk Touch (`/enchant @s silk_touch` on a pickaxe, and check the tooltip). A normal pickaxe drops nothing. Silk Touch drops the glass. That is the static loot table on current core. Block breaks do not call `get_predicate`, so this branch must not change those two results. A datapack loot table that references a predicate is not resolved during a break.
7. Pick up a crafting table. `story/root` does not grant yet. A-43 and A-44 call `get_predicate` for advancements.

Capture: the console after boot and after `reload`, showing the three embedded predicates, the unknown-type line, and no panic.
