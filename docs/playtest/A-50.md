# A-50 playtest: scoreboard and team display names

Use an operator on a new world. The chat line is the check. `objectives list` and `objectives setdisplay` are A-51, so the sidebar does not show the objective yet. `team modify displayName`, `prefix`, and `suffix` still take a raw string. Do not fail this list because those three keep the quote characters.

1. `/scoreboard objectives add kills dummy "Kills"`
   Expect `Created new objective Kills`. The word Kills has no quote characters.

2. `/scoreboard objectives add styled dummy {"text":"Kills","color":"gold"}`
   Expect `Created new objective Kills`, with Kills in gold. The chat does not show the JSON text.

3. `/scoreboard objectives add plain dummy`
   Expect `Created new objective plain`.

4. `/team add red "Red"`
   Expect `Created team Red`, with no quote characters.
   `/team list` expects one team and the name Red, not `"Red"`.
   `/team list red` expects `There are no members on team Red`.

5. `/team add blue {"text":"Blue","color":"blue"}`
   Expect `Created team Blue`, with Blue in blue.
   `/team list` shows Blue in blue, not the JSON text.

6. `/team add green`
   Expect `Created team green`.
   `/team list green` expects `There are no members on team green`.

7. Stop the server and start it again. `/team list`
   Expect Red, Blue, and green with the same display names as steps 4, 5, and 6. Blue is still blue. A restart reads the shared `scoreboard.dat` from A-05.
