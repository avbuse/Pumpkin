# A-48 play test

Open a world that vanilla 26.3 saved, in Pumpkin. The dedicated server jar is data version 5023. Do not use a world from 26.2 or earlier for the first pass. Those still have to load, but this check is the 5023 palette.

## Load a vanilla 26.3 world

1. Create a world in vanilla 26.3 (single player or the dedicated server). Remember the seed.
2. Stop vanilla so the region files are flushed.
3. Start Pumpkin with that world directory as its level.
4. Join with a 26.3 client.

Expect the terrain you left, not a hollow of air. In the overworld:

- The bottom of the world (`y = -64`) is bedrock, not air.
- The deepslate band below the stone is deepslate, not air.
- Stone, dirt, grass, sand, and logs are the blocks you remember, including their default states. A default furnace (facing north, unlit) is a furnace, not air.
- A non-default state stays exact. Oak stairs facing east stay oak stairs facing east. A lit furnace facing east stays lit and facing east.
- Biomes look the same as they did in vanilla. Water and lava still flow from the blocks that were there.
- Chests, furnaces, signs, and decorated pots still have the items and text you left. Pumpkin does not rewrite sherd lists, furnace times, or brewing numbers.

A world that used to open as mostly air and now shows the original ground is the change.

## Edit, save, reopen in vanilla

1. In Pumpkin, break one block and place oak stairs facing east, a furnace, and a stone block in a chunk you can find again. Note the coordinates.
2. Stop Pumpkin with `stop` and wait until the save finishes.
3. Open the same world in vanilla 26.3.

Expect:

- Vanilla opens the world with no chunk-load error in the log.
- The terrain Pumpkin did not touch is unchanged.
- The stairs, furnace, and stone you placed are those blocks, with the facing you set.
- The furnace inventory and any sign text you did not edit are still there.

## A 26.2 world still loads

1. Create a small world in vanilla 26.2 and place a furnace or a stone block you can find again. Stop vanilla.
2. Copy that save in as Pumpkin's `world/` (the directory that contains `level.dat`). Start this branch and join.

Expect terrain rather than air, and the furnace or stone still that block. Data version 4903 is inside the supported range (4435 through 5023). Tag upgrades are not required.

A world the server rejects with `Unsupported world version` is outside that range. 26.2 and 26.3 are inside it.

## A world saved by current core

`core-functionality` writes `Name` / `Properties` palettes and labels them 5023. Vanilla then logs `Recoverable errors when loading section` and reads most of the section as air. This branch still reads that shape, and a save here rewrites it as 5023.

1. On `core-functionality` `70a0b846e`, place oak stairs facing east, a furnace, and stone. `stop`.
2. Copy that `world/` onto this branch. Join.
3. Expect those blocks, not air.
4. `stop` on this branch. Open the same world in vanilla 26.3.

Expect no `Recoverable errors when loading section`, and the stairs, furnace, and stone still there.

This branch does not contain the level time, weather, border, and scoreboard restore that is already on `core-functionality`. A reset of those values is not a fail of this checklist.
