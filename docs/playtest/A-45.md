   cargo test -j 2 -p pumpkin-world --lib generation::proto_chunk_test -- --nocapture --test-threads=2

Expect no visible difference from `core-functionality`, because this branch does not change the generator. This check does not show whether terrain matches vanilla. The fixture counts are that measurement.
