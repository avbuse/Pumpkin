# A-45 playtest

This branch records the world generation mismatch baseline. It does not change generation, chunk format, or packets. A player on this branch should see the same terrain as `core-functionality` at `70a0b846e`.

The numbers to hold are in [WORLDGEN_BASELINE.md](../compat/WORLDGEN_BASELINE.md). A higher count is a regression even when the test still passes under its allowance.

## Checklist

1. Diff `crates/` against `core-functionality`. Expect no Rust changes. The allowances in `verify_chunk_noise` (6000), `verify_chunk_surface` (7500), and `verify_chunk_carvers` (8000) stay as they are.
2. From the repository root, run:

   ```bash
   cargo test -j 2 -p pumpkin-world --lib generation::proto_chunk_test -- --nocapture --test-threads=2
   ```

   Expect `43 passed; 0 failed`. Expect the suite totals noise 2, surface 2846, carvers 9122, and the same per-chunk cells as the baseline note. A missing `Total mismatches` line on a passing test means 0.
3. Boot the server from a scratch directory (`cargo run --manifest-path <repo>/Cargo.toml -p pumpkin`). Wait for the done line. Send `stop`. Expect no panic from this branch.
4. Join with a 26.3 client and create a new world, seed 0. Walk a few chunks around spawn. Expect the world to generate and the player to stand on solid ground. Expect no visible difference from `core-functionality`, because this branch does not change the generator. This check does not show whether terrain matches vanilla. The fixture counts are that measurement.

Capture: none required. Nothing a player can see changed. If you still record a clip, show the done line and the player standing on generated ground.
