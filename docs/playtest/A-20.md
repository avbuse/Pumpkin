# A-20 Chest and barrel inventories persist

Join with a Java 26.3 client. Use a new world, or one you can throw away.

Closing the chest or barrel window only updates the live inventory. The chunk snapshot is written when the chunk unloads, when you run `/save-all`, when the server stops, and on the periodic autosave (every 6000 ticks by default). The autosave used to skip that copy, so a crash after it could leave a chest empty.

1. Place a chest. Put a stack of cobblestone in the first slot. Close the chest. Open it again. The cobblestone is still in that slot.
2. Place a second chest against the first so they join into one double chest. Put diamonds in a slot on the left half and emeralds in a slot on the right half. Close the window and open either half. Both stacks are still in those slots, and the window is the large double-chest window.
3. Stop the server with `stop`, start it again, and open the double chest. Both stacks are still there.
4. Place a barrel. Put one stack of oak planks in it. Close it, open it again, then stop and start the server. The planks are still in that slot.
5. Break the chest. The diamonds and emeralds drop. Open the barrel again. The planks are still there.
6. Place another chest, put 16 cobblestone in the first slot, and close it. Note the coordinates. In creative, fly at least 400 blocks away so the chunk unloads (view distance is 16), then fly back and open the chest. The cobblestone is still there.
7. Stop the server. In `pumpkin.toml`, under `[world]`, set `autosave_ticks = 200`. Start again. Place a chest and a furnace in the same chunk. Put 16 cobblestone in the chest and one coal in the furnace fuel slot. Close both. Stay in the chunk. Do not run `save-all` and do not type `stop`. Wait for `Saving <N> chunks (collected from <M> holders)...`, then `kill -9` the server process. Start again. The cobblestone and the coal are still there. `stop` and `save-all` already copied live inventories before this branch, so they do not prove the autosave fix. Put `autosave_ticks` back to 6000 when you finish.
8. Place a trapped chest, put one iron ingot in it, close it, `stop`, and start. The ingot is still there. Redstone output is not part of this check.
