# A-06 playtest

A survival player who logs out and comes back after a restart keeps the same health, hunger, inventory, spawn point, and gamemode.

Use a 26.3 Java client on a new world. The default gamemode is survival, and the account you join with can run operator commands.

## Checklist

1. Join. Expect full health, a full hunger bar, an empty inventory, and survival (no flying, and you can take damage).
2. Run `/give @s diamond 3` and `/give @s iron_helmet`. Put one diamond in the off-hand and wear the helmet. Put one emerald in an ender chest.
3. Run `/damage @s 7`. Expect the health bar to drop by three and a half hearts.
4. Sprint and jump until the hunger bar loses at least one shank.
5. Stand on a block you can recognize, away from world spawn, and run `/spawnpoint`. Note those coordinates. Optional: `/spawnpoint @s ~ ~ ~ 90 10` so the saved facing is not zero.
6. Run `/gamemode creative`, then `/gamemode survival`. You should be in survival again.
7. Disconnect. Stop the server with `stop`. Start it again in the same directory and rejoin.
8. Expect the same health, the same hunger, three diamonds with one of them in the off-hand, the iron helmet still worn, and the emerald still in the ender chest.
9. Expect survival: hearts are not full if you left them low, you cannot fly, and blocks break at survival speed.
10. Die in a hole or with `/kill`. Expect to respawn at the spawnpoint from step 5, facing the yaw you set. Item drops on death are A-27 and are not part of this check.

## Missing player file

Stop the server, delete that player's file under `world/playerdata/`, and start again. Rejoin. Expect a new survival player: full health, full hunger, an empty inventory, no personal spawnpoint, and survival gamemode.
