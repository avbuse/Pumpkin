## 1. Blocking: Sweeping Edge now does nothing

`5f588c7` removed the level fallback. The sweep reads only `Attributes::SWEEPING_DAMAGE_RATIO`. Nothing in Pumpkin applies enchantment attribute effects:

- `pumpkin-data` `Enchantment::SWEEPING_EDGE.effects` has no attributes entry, because the codegen does not emit `minecraft:attributes`.
- `living.rs` only applies item `attribute_modifiers`.

So the ratio is always 0 and the sweep deals 1. `core-functionality` today still applies Sweeping Edge in the old attack code, so merging this branch as is loses it.

Fix, following AGENTS.md:
- Extend `tools/pumpkin-codegen` to generate the enchantment `attributes` effect.
- Apply those modifiers when equipment changes, beside the item modifiers in `apply_equipment_slot_attribute_modifiers`.
- Do not bring back the hardcoded `level / (level + 1)`.

## 2. Playtest step 6 uses removed NBT

`docs/playtest/A-24.md` step 6 summons with `ArmorItems:[...]`. 26.3 reads mob equipment from `equipment`, so that zombie spawns without armour and the expected 16.16 never shows. Use:

```
/summon zombie ~ ~1 ~ {Health:20f,NoAI:1b,equipment:{chest:{id:"minecraft:leather_chestplate",count:1}}}
```
