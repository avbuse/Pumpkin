## 1. Remove the hand-written Efficiency sync

`Player::sync_mining_efficiency` (`player.rs` around 5128) still adds `minecraft:enchantment.efficiency` to `MINING_EFFICIENCY` with a hardcoded `level * level + 1`. The generated Efficiency entry now does the same thing (`LevelsSquared { added: 1 }`) through the equipment path.

Both use the same modifier id, so nothing is counted twice today. It is still a second, hardcoded copy of data that is now generated. Remove `sync_mining_efficiency` and `synced_mining_efficiency_level`, and check that mining speed still picks up Efficiency right after a hotbar change.
