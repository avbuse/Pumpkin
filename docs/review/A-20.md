## 1. Autosave now rewrites every chunk that has any block entity

`save_block_entities` calls `add_block_entity_nbt` for every live block entity. That marks the chunk dirty. So each autosave (every `autosave_ticks`) dirties every loaded chunk that holds a chest, furnace, sign, bed or anything else, changed or not. The chunk saver then rewrites all of them.

Vanilla only rewrites chunks whose block entities called `setChanged()`.

Most block entities here already keep a dirty flag (`is_dirty` / `clear_dirty`). In the autosave path, copy only entities whose flag is set, then clear it. Otherwise a base full of chests makes every autosave a full rewrite of those chunks. Unload and shutdown can stay as they are.
