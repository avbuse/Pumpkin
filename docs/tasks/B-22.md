## Goal

When an admin enables it, mobs outside a per-type range skip their AI tick and still tick when a player is close, when they are in water, or when they have a target. Default off means every mob in simulation distance ticks as it does today.

## Files and crates

- `crates/pumpkin-core/src/entity/mob/mod.rs`
- `config`

## Acceptance criteria

- Flag off: a distant mob still ticks.
- Flag on: a distant mob without a target does not run its goals.
- Flag on: a mob next to a player does run its goals.

## Verification

Gametest with the flag forced on in that world only.
