## Goal

World::load builds a fresh clock, clear weather, the default border, and an empty scoreboard. LevelTime::load_from already exists and has no caller. On load, fill those objects from level.dat and the scoreboard save. A restart must show the saved day time, the saved weather, the saved border, the saved gamerules, and the saved objectives.

## Files and crates

- `crates/pumpkin-core/src/world/mod.rs`
- `crates/pumpkin-core/src/world/time.rs`
- `crates/pumpkin-core/src/world/weather.rs`
- `crates/pumpkin-core/src/scoreboard/`

## Acceptance criteria

- After a stop and start, the day time matches the value that was saved.
- Rain or thunder that was saved is still active.
- A non-default border centre and size survive.
- A scoreboard objective created before the restart is still there.
- A world with those sections missing still boots with the current defaults.

## Verification

Boot the server, set the time with the console, stop, start, and query the time. A unit test around the NBT decode is welcome if it does not need a full world.

## Out of scope

- Entity spatial indexes. B-03 owns get_entities_at_box.
- Player inventory. A-06 owns player NBT.
- Editing the entity tick loop.
