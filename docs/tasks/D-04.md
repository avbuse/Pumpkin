## Goal

Forward an accepted voice payload to authenticated players inside the configured distance, and not to players outside it. An operator mute drops that speaker's packets. Group isolation, if the D-01 note says the client already has groups, is a single room id check. Do not record audio.

## Files and crates

- `the voice module from D-03`

## Acceptance criteria

- Two players inside range both receive each other's payload.
- A player outside range does not.
- A muted speaker is not forwarded.
- No audio is written to disk.

## Verification

Three fake UDP peers in a unit test with positions supplied directly.

## Out of scope

- A Pumpkin-specific client mod.
- Voice replay.
