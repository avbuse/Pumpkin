## Goal

A client in configuration can send keep-alive. handle_config_packet treats that id as unknown and kicks. Dispatch it the same way play keep-alive is answered, and leave the connection in configuration. Unknown ids other than the ones this task and A-12 name still kick.

- Play keep-alive behaviour is unchanged.
