## Goal

Density functions are walked as a tree. Flatten one hot node type into a specialised evaluator and constant-fold its literal children. Output for a fixed seed and chunk matches the tree walker. Leave the other node types on the walker.

## Files and crates

- `crates/pumpkin-world/src/generation/ (density functions)`

## Acceptance criteria

- The specialised node matches the walker on a fixed grid of inputs.
- Other nodes are unchanged.
- Mismatch counts stay within the baseline.

## Verification

A unit grid comparison.

## Out of scope

- A full SIMD port of every noise type.
