## Goal

Right-click toggles the open state of a wooden door, a trapdoor, and a fence gate. A door updates both halves. Redstone-powered opening can stay as it is if it already works.

## Files and crates

- `crates/pumpkin-core/src/block/blocks/doors.rs`
- `the trapdoor and fence-gate block files`

## Acceptance criteria

- Right-click toggles open on each of the three block kinds.
- The upper and lower door halves agree.
- A second click closes them.

## Verification

Harness setblock plus use-item-on, or a gametest.

## Out of scope

- Iron doors, which are redstone-only.
- Redstone power. Phase A redstone tasks own that.
