## Goal

Packet compression uses flate2 with the rust backend. Benchmark libdeflate or zlib-rs on the same chunk packet bytes. Switch the default only if the benchmark shows a clear CPU drop and the decompressed bytes match. Keep the old backend selectable.

## Files and crates

- `crates/pumpkin-core/src/net/ (compression)`
- `a bench or an ignored test`

## Acceptance criteria

- A table of compress and decompress times on one fixed buffer is in the PR description the human will use.
- Decompressed output matches the current backend.
- If you switch, a config or feature flag can return to the old backend.

## Verification

A criterion or a timed ignored test. Quote B-01 percentiles if you change the default.

## Out of scope

- Caching compressed chunk frames. B-07.
- Hand-writing SIMD.
