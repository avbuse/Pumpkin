## Goal

Add a second dust implementation that updates power the way Alternate Current does: collect the network and apply it, instead of the vanilla walking evaluator. Select it with redstone.implementation = vanilla or alternate_current. The default is vanilla, and the A-37 fixture passes on vanilla. Document that alternate_current changes update order.

## Files and crates

- `crates/pumpkin-core/src/block/blocks/redstone/redstone_wire.rs`
- `config`

## Acceptance criteria

- Default config passes the A-37 dust fixture.
- The alternate engine powers a straight line of dust.
- The config key defaults to vanilla.

## Verification

Gametest twice, once per engine, if the test harness can set config. Otherwise the alternate engine has its own unit fixture and vanilla stays on the gametest.

## Out of scope

- Porting Alternate Current by translating its Java.
- Changing the vanilla evaluator.
