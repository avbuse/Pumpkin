## Goal

The page can poll a JSON endpoint of online players' dimension and block position. Vanished players from C-09 are omitted if that flag exists. Positions update without reloading the page. The poll interval is at least one second.

## Files and crates

- `the map HTTP module`

## Acceptance criteria

- The JSON lists a normal player.
- A player who logged out disappears on the next poll.
- The endpoint does not include inventory or chat.

## Verification

Harness login plus an HTTP GET.

## Out of scope

- Websocket push. Polling is enough.
