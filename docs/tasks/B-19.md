## Goal

Replace the unordered parallel entity tick with a pass that ticks each region to completion. Inside a region, entity order is stable. The default single-region mode is the vanilla-style order. Multi-region mode may tick different regions at the same time, and must not tick the same entity twice or skip one.

## Files and crates

- `crates/pumpkin-core/src/world/mod.rs`

## Acceptance criteria

- Every entity ticks once per server tick.
- Order inside a region matches the stable sort from B-17.
- Default config does not run two entity ticks in one region at the same time.
- Combat and redstone gametests from phase A still pass.

## Verification

The order test from B-17, plus pumpkin_smoke. Record MSPT percentiles.

## Out of scope

- Changing AI goals.
- Making multi-region the default.
