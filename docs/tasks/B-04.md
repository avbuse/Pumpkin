## Goal

Tracking and nearby-player lookups should use a coarser player map built on the section index, so a broadcast does not walk every player. Results match the current player list for a small server.

## Files and crates

- `crates/pumpkin-core/src/world/entity_tracker.rs`
- `the spatial module from B-03`

## Acceptance criteria

- A player lookup at a position returns the same players as the old scan on a 10-player fixture.
- A player changing dimension leaves the old map.

## Verification

Unit fixture.

## Out of scope

- Per-type view distance config beyond what the tracker already stores.
