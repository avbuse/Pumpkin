## Goal

The server already tracks tick durations. Expose p50, p95, and p99 over a fixed window, and split the tick into the phases the world tick already times: entities, block entities, chunks, lighting, network flush, and plugins. /tps prints the percentiles. Default behaviour of the tick does not change.

## Files and crates

- `crates/pumpkin-core/src/server/ticker.rs`
- `crates/pumpkin-core/src/command/commands/tps.rs`

## Acceptance criteria

- /tps includes p50, p95, and p99.
- A phase that did not run shows a zero duration.
- The tick loop still finishes a tick when the new timers are allocated once.

## Verification

Boot the server, run /tps from the console, and check the log line. A unit test of the percentile function with a fixed sample is the regression test.

## Out of scope

- A sampling profiler. B-02.
- Changing tick order.
