## Goal

26.3 client information ends with a particle-status varint. All is 0. Pumpkin's configuration codec stops at server listing. Real clients still join because the extra bytes are ignored, and a packet Pumpkin writes is rejected by a vanilla 26.3 server. Read and write the field on both the configuration and play client-information packets. Then stop the harness from appending a second particle-status byte.

## Files and crates

- `crates/pumpkin-protocol/src/java/server/config/client_information.rs`
- `crates/pumpkin-protocol/src/java/server/play/ (the play client-information packet, if it has the same cutoff)`
- `tools/pumpkin-compat/src/client.rs`

## Acceptance criteria

- A packet with particle status 0 decodes, and the written bytes include that trailing varint.
- The harness sends the field once.
- pumpkin_smoke and vanilla_milestones both pass.

## Verification

The compat smoke tests. A codec round-trip with status 0, 1, and 2 if those are the documented values.
