## Goal

Scheduled block ticks should be ordered by time, priority, and sub-order in one key, and an empty section should not run random ticks. Order of two ticks scheduled for the same time matches the current order.

## Files and crates

- `the scheduled tick structure under crates/pumpkin-core/src/world/ or block/`

## Acceptance criteria

- Two ticks at the same time run in the same order as before.
- An empty section schedules no random tick work.

## Verification

A unit test of the queue.

## Out of scope

- Random tick game rules.
