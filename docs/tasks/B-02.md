## Goal

Add /pumpkin profile for a short window. It samples the process with pprof or an equivalent already acceptable to the workspace and writes a file under the server directory. The command is operator-only. It does not start sampling at boot.

## Files and crates

- `crates/pumpkin-core/src/command/commands/pumpkin.rs`
- `Cargo.toml of pumpkin-core for an optional dependency`

## Acceptance criteria

- An operator can start and stop a profile and get a file path.
- A non-operator cannot.
- The server ticks normally when the command has never been used.

## Verification

Console command on a dev server. Record the before/after of B-01 percentiles around one profile run so the overhead is visible.

## Out of scope

- Tracy as a required dependency.
- A public metrics endpoint. Leave a follow-up note if you touch config.
