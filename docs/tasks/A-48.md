## Goal

Update the Anvil chunk codec for the fields A-08 listed. Read old 4903 chunks that are still inside the supported range, and write 5023. If A-08 found no field changes, this task is a regression test that a 5023 chunk round-trips, and you stop there.

## Files and crates

- `crates/pumpkin-world/src/chunk/format/`

## Acceptance criteria

- Each field named in the A-08 note is read and written.
- A chunk written by Pumpkin loads again with the same block states.
- A 4903-shaped chunk that omits a newly added optional field still loads.

## Verification

Unit round-trip of a synthetic chunk NBT. No Mojang region files in git.

## Out of scope

- A general DataFixer for versions before 4435.
- Compression id 127. A-07.
