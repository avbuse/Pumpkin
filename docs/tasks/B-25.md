## Goal

/locate currently searches on the tick. Run the search on the worker pool and deliver the result on a later tick. The position matches a synchronous search for the same seed. The command responds even when the structure is missing.

## Files and crates

- `crates/pumpkin-core/src/command/commands/locate.rs`

## Acceptance criteria

- The located position matches the sync function.
- The tick that starts the search does not run the scan inline.
- A miss sends the vanilla-style failure message.

## Verification

A unit test with a stub structure index, plus one console locate on a dev world.
