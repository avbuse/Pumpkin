## Goal

Write docs/research/voice-chat.md from public docs. Simple Voice Chat needs a client mod, uses a plugin message to hand the client a secret and a UDP host and port, and defaults that UDP port to 24454. Audio is Opus. The project documents AES on the UDP payloads. Plasmo Voice also needs a client mod, uses a separate UDP socket, and by default binds UDP on the same port number as the Minecraft TCP port. Players without the mod still play. Recommend implementing the Simple Voice Chat split (plugin channel for setup, UDP for audio) so an existing client mod can connect, and say what is not public enough to implement yet. Do not paste source from either project. Record their licences.

## Files and crates

## Acceptance criteria

- The note covers the TCP setup versus UDP audio split, the client-mod requirement, and the default ports.
- It names Opus and says the server must not decode audio on the tick thread.
- It states that a vanilla client is unaffected when voice is disabled.
- No Java source is included.
