## Goal

When enabled, a configurable join message is sent and a new player receives a configured starter stack once. Existing players do not receive the kit again. Flag off means no message and no items.

## Files and crates

- `the player join path`
- `config`

## Acceptance criteria

- Flag off: no extra message and an empty new inventory.
- Flag on: the message is sent and the stack is given once.
- A rejoin does not give a second kit.

## Verification

Harness login.
