## Goal

Render a loaded chunk into a top-down tile image using the block colours already available in the generated data. Write the tile to the server directory. Unloaded chunks produce no tile. This is the squaremap-style 2D tile, not a 3D mesh.

## Files and crates

- `a new map module`
- `crates/pumpkin-data block colours if they already exist`

## Acceptance criteria

- A chunk of grass over stone produces a tile file.
- A chunk that is not loaded produces nothing.
- Rendering does not run on the game tick. Spawn it on a blocking or rayon pool.

## Verification

A unit test with a synthetic chunk section.

## Out of scope

- 3D PRBM tiles.
- An HTTP server. D-06.
