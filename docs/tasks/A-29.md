## Goal

A skeleton with a line of sight fires an arrow on its vanilla interval using the arrow entity from A-25. Without a line of sight it does not fire.

## Files and crates

- `crates/pumpkin-core/src/entity/mob/skeleton.rs`

## Acceptance criteria

- One arrow is spawned toward the target when the skeleton can see it.
- No arrow is spawned when a solid block blocks vision.

## Verification

Gametest that ticks the skeleton goal.

## Out of scope
