## Goal

Serve the tiles and a single HTML page from an HTTP port bound to localhost by default. The port is config. Flag off binds nothing. A missing tile returns an empty response rather than a server error. The page loads a tile by chunk coordinate.

## Files and crates

- `the map module`
- `config`

## Acceptance criteria

- Flag off: nothing listens.
- Flag on: a GET for an existing tile returns the image.
- A GET for a missing tile does not return 500.
- The bind address defaults to localhost.

## Verification

Start the server in a test with the flag on and request one tile.

## Out of scope

- Authentication. D-08.
- Player markers. D-07.
