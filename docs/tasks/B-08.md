## Goal

The chunk system already has a scheduler and a generation pool. Add distance-based priority and an urgent priority for loads the tick is waiting on. In the I/O queue, run a read of a chunk before a write of that same chunk. Generation results stay the same.

## Files and crates

- `crates/pumpkin-world/src/chunk_system/schedule.rs`

## Acceptance criteria

- A nearer chunk is queued ahead of a farther one.
- A read does not wait behind a write of the same coordinate.
- Existing chunk tests pass.

## Verification

A scheduler unit test with scripted tasks.
