# A-16 Sleep in a bed and set the spawn

## Goal

A player who right-clicks a bed at night, with the vanilla nearby-monster and dimension rules satisfied, enters the bed and the bed becomes their spawn. Leaving the bed or failing the check leaves the block unused. Daytime sleep fails with the usual message.

## Files and crates

- `crates/pumpkin-core/src/block/blocks/bed.rs`

## Acceptance criteria

- A valid night sleep sets the respawn position to that bed.
- Sleeping in the daytime does not set the spawn.
- A bed with a monster inside the vanilla check radius does not start sleep.

## Verification

Harness or gametest. Respawn after death is A-27.

## Out of scope

- Skipping the night for the whole server if that already exists elsewhere.
- Respawn packet flow. A-27.
