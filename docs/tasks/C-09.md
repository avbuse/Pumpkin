## Goal

An operator can vanish. Other players do not receive that player as an entity or a tab entry. The vanished operator still receives the world. Flag off means the command is unregistered. Chat from a vanished operator is still sent unless C-04 muted them.

## Files and crates

- `a vanish command`
- `entity tracker and tab list`

## Acceptance criteria

- Flag off: unregistered.
- Flag on: a second client does not get a spawn packet for the vanished player.
- The vanished player still gets chunk packets.

## Verification

Two harness clients.
