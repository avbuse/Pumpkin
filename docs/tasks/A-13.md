## Goal

Right-click with an axe, shovel, or hoe should change the targeted block the way vanilla does for the common cases: logs to stripped logs, grass or dirt to dirt path, and dirt or grass to farmland. The item files already exist. Finish the missing interactions. Play the existing block sound if the server already has a sound helper for that action.

## Files and crates

- `crates/pumpkin-core/src/item/items/axe.rs`
- `crates/pumpkin-core/src/item/items/shovel.rs`
- `crates/pumpkin-core/src/item/items/hoe.rs`
- `crates/pumpkin-core/src/item/items/mod.rs`

## Acceptance criteria

- Oak log becomes stripped oak log.
- Grass block becomes dirt path under a shovel.
- Dirt becomes farmland under a hoe when the vanilla moisture and space rules allow it.
- A stick does not strip, path, or till.

## Verification

Harness scenario using setblock plus use-item-on, or a gametest. One case per tool.

## Out of scope

- Every wood type if the first three cases are data-driven and already covered.
- Combat damage. A-24.

## Also done

The branch is `core/A-13-tool-actions`. The transformer tables also cover copper, so the branch does two things the original three cases did not name:

- Copper doors are rewritten as a pair in `axe.rs`. Both halves keep their properties, and the placement callback is skipped so an upper half does not write a door into the block above it.
- Copper chests, including waxed chests, scrape and dewax. The other half of a double chest updates in `CopperChestBlock`'s neighbour update (`chests.rs`), which `/setblock` runs as well. Replacing one copper chest with another keeps the block entity (`world/mod.rs`), so the items stay. The axe only sends the block-change game event and the particle for that neighbour.
- A shield in the off hand makes a main-hand axe, shovel, or hoe pass unless the player is sneaking. Campfire dousing still runs, because that click belongs to the campfire.
