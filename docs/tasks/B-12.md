## Goal

The light engine already has increase and decrease queues. Store the direction and the special-shape flags in the queue entry so a node is not expanded back the way it came when the vanilla engine would skip that. Light values on a fixed chunk match the current engine.

## Files and crates

- `crates/pumpkin-world/src/lighting/engine.rs`

## Acceptance criteria

- A chunk's light array matches the pre-change engine on a fixed block fixture.
- The queue entry carries a direction.

## Verification

An existing lighting test, or a new one with a sky-light column and one opaque block.

## Out of scope

- Parallel light. B-13.
