## Goal

Entities currently tick in parallel chunk batches, so order inside a neighbourhood is not the vanilla order. Write the design for regionised ticking: the world is split into regions, a region ticks its entities in a fixed order, and the default mode is one region for the whole dimension so the order is sequential. Land the config switch defaulting to that single-region mode. Do not change the tick body in this task beyond honouring the switch as a sequential path that calls the existing per-entity tick.

## Files and crates

- `docs/compat/REGION_TICKING.md`
- `crates/pumpkin-core/src/world/mod.rs`
- `config`

## Acceptance criteria

- The design names the region size, the ownership rule, and what stays on the main tick.
- The default config ticks entities sequentially.
- A test records that two entities in the same chunk run in a stable order.

## Verification

A gametest or unit test of order. Quote B-01 before and after in the notes.

## Out of scope

- The ownership map. B-18.
- Parallel regions as the default.
