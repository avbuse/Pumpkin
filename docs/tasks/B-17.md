## Goal

Entities currently tick in parallel chunk batches, so order inside a neighbourhood is not the vanilla order. On core, tick entities one after another in a stable order and call the existing per-entity tick. Write the region design in the note: region size, ownership, and what stays on the main tick, and say that the ownership map and parallel regions are B-18 and B-19 on enhanced-functionality. Do not add a multi-region mode in this task.

## Acceptance criteria

- The design names the region size, the ownership rule, and what stays on the main tick.
- Core has no multi-region switch. Entities tick sequentially.
- A test records that two entities in the same chunk run in a stable order.
