## Goal

A survival player who logs out must come back with the same health, hunger, inventory, spawn point, and gamemode. Follow the existing player NBT read and write path and close the fields that are still dropped. Movement stays client-authoritative.

## Files and crates

- `crates/pumpkin-core/src/entity/player.rs`
- `crates/pumpkin-core/src/entity/hunger.rs`

## Acceptance criteria

- Health, food level, inventory contents, spawn position, and gamemode survive a rejoin on the same world.
- A missing or partial player file still joins with a new survival player.
- The ender chest, if it is already persisted, is unchanged.

## Verification

Harness or console: give an item, set health, stop, start, rejoin, and read the slot and health. A-03 helps once it has landed. A unit round-trip of the player NBT compound is enough if the harness helper is not ready.

## Out of scope

- Death and respawn rules. A-27 owns those.
- Combat math. A-24 owns that.
