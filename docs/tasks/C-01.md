## Goal

Operators, or players if the config flag is on, can save a named home and teleport back. The flag defaults off, and off means the commands are unregistered. Homes persist in the world save.

## Files and crates

- `crates/pumpkin-core/src/command/commands/home.rs`
- `crates/pumpkin-core/src/command/commands/mod.rs`

## Acceptance criteria

- Flag off: the command is not registered.
- Flag on: set and teleport work across a restart.
- A second home name does not overwrite the first.

## Verification

Console or harness command sequence.

## Out of scope

- Cross-dimension homes if the teleport helper cannot change dimension yet. Same-dimension is the exit.
