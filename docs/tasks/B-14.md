## Goal

Add /pumpkin pregen for a radius around a centre, with start and cancel. It uses the existing generation pool. It does not change chunks that already exist. Operators only.

## Files and crates

- `crates/pumpkin-core/src/command/commands/pumpkin.rs`

## Acceptance criteria

- A radius 1 pregen fills the missing chunks and leaves existing chunks in place.
- Cancel stops further scheduling.
- A non-operator cannot run it.

## Verification

Console on a scratch world. Record chunks per second with B-01 timings in the human's notes.

## Out of scope

- Chunky-compatible region shapes beyond a square radius.
