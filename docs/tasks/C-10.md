## Goal

When enabled, /back returns the player to the position of their last death or the last teleport this command set. Flag off unregisters it. Only one position is stored.

## Files and crates

- `crates/pumpkin-core/src/command/commands/back.rs`

## Acceptance criteria

- Flag off: unregistered.
- After death, back returns the player to the death position.
- A second back does not loop further than that saved position.

## Verification

Harness with A-27's death flow.

## Out of scope

- A stack of previous positions.
