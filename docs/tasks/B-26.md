## Goal

Jigsaw assembly tests piece overlaps with a linear scan. Use a grid or box tree of placed piece bounds. The chosen pieces for a fixed seed match the linear version.

## Files and crates

- `crates/pumpkin-world/src/generation/ (jigsaw / template pool placement)`

## Acceptance criteria

- A structure placed with the index matches the linear overlap result on a fixed seed.
- The index is updated when a piece is accepted.

## Verification

An existing structure test, or one template-pool fixture.

## Out of scope

- New structures. A-46 owns features.
