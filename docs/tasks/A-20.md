## Goal

Opening a chest or a barrel shows its inventory. Items placed in it are still there after the window closes and after a chunk reload. A double chest already paired by the existing code keeps a shared inventory.

## Files and crates

- `crates/pumpkin-core/src/block/blocks/chests.rs`
- `the barrel block file if it is separate`

## Acceptance criteria

- A stack inserted into a chest is readable after reopening.
- The same stack is readable after the chunk is saved and loaded.
- A barrel does the same for one stack.

## Verification

Harness window clicks, or a gametest that writes the block entity NBT and reads it back.

## Out of scope

- Trapped chests' redstone output.
- Hoppers. A-21.
