## Goal

Write docs/research/audit-replay.md and add the config keys, defaulted so that nothing is recorded. Cover retention, who can roll back, and that chat, container contents, and voice are off unless an admin turns them on. Block changes are the first thing a later task may record. Say that a rollback log is not a world backup. Session replay, if enabled later, stores positions and block changes, and downloading a replay is off by default.

## Files and crates

- `docs/research/audit-replay.md`
- `pumpkin config`

## Acceptance criteria

- Defaults record nothing.
- The note lists chat, containers, voice, and replay download as off by default.
- The note says operators should take a world backup before a rollback.

## Verification

A config load test, or the server boot with no audit files created.
