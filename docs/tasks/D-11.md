## Goal

An operator can query the block log at a position and roll those rows back. Rollback applies the previous state and writes a new row so the rollback itself is logged. A default radius is small and must be printed in the command output. Flag off unregisters the command. This does not restore a corrupted region file.

## Files and crates

- `a new command file`
- `the log module`

## Acceptance criteria

- Lookup prints the place and break from D-10.
- Rollback restores the previous block.
- The rollback is a new log row.
- Flag off: unregistered.

## Verification

Harness: place, roll back, read air or the original block.

## Out of scope

- Global rollback.
- Inventory rollback.
