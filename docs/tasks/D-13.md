## Goal

Add an operator command that exports one recording to a folder another tool can read, and a way to play the positions and block changes back on a test server as console setblocks over time. Downloading the file from the map server is off. Do not claim ReplayMod compatibility unless the export bytes were checked against a published format description.

## Files and crates

- `the recording module`
- `a command file`

## Acceptance criteria

- Export writes a folder an operator can find.
- Playback on a scratch world rewrites the recorded block change.
- The map HTTP server does not serve the file.

## Verification

The D-12 unit fixture plus one playback test.

## Out of scope

- Shipping a client mod.
- Recording other players' inventories.
