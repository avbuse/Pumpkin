## Goal

The first story advancements that only need inventory, placed-block, or enter-block criteria should grant during play and the client should receive the progress packet. List the advancement ids the task actually covers in the commit's surrounding note in the task PR description the human will write. Stop after that opening set.

## Files and crates

- `crates/pumpkin-core/src/entity/player/advancement/`

## Acceptance criteria

- Obtaining the item named by the first story advancement grants it.
- The client receives a progress update.
- An advancement outside the listed set is unchanged.

## Verification

Harness: give the item and watch for the advancement packet.

## Out of scope

- Adventure and nether tabs.
- Recipe unlock toasts beyond the packet that already exists.

## Rules

Read `docs/tasks/README.md` before starting. One task on one branch. Commit with `git commit -s`. Push only to `avbuse/Pumpkin`. Do not open a pull request and do not push to `Pumpkin-MC/Pumpkin`. Do not commit a Mojang jar, region file, or decompiled source, and do not paste Java into the repo. Class names in the research notes are pointers. Reimplement from the description.
