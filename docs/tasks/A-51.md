## Goal

`/scoreboard objectives setdisplay sidebar <objective>` and `/scoreboard objectives list` fail to parse. The `objectives` tree only registers `add` and `remove`. Vanilla also has `list` and `setdisplay <slot> [<objective>]`. Omitting the objective clears the slot. `Scoreboard::set_display_objective`, `clear_display_objective`, and `get_objectives` already exist. Call those. Add a slot argument that maps vanilla's names onto `ScoreboardDisplaySlot` and reports `minecraft:scoreboard_slot` to the client. Do not add a second slot enum.

## Files and crates

- `crates/pumpkin-core/src/command/commands/scoreboard.rs`
- `crates/pumpkin-core/src/command/argument_types/` (a display-slot argument beside `objective.rs`)
- `crates/pumpkin-data/src/generated/scoreboard_slot.rs` (`ScoreboardDisplaySlot`, read it, do not edit it)
- `crates/pumpkin-core/src/world/scoreboard.rs` (call `set_display_objective` and `get_objectives`; stay out of this file unless a slot name is missing)

## Acceptance criteria

- `scoreboard objectives list` parses with no errors and consumes the whole line.
- With no objectives, list feedback uses `commands.scoreboard.objectives.list.empty`. With objectives, it uses `commands.scoreboard.objectives.list.count` and `commands.scoreboard.objectives.list.entry`.
- `scoreboard objectives setdisplay sidebar <objective>` parses, and `get_display_objective(Sidebar)` is that objective.
- `scoreboard objectives setdisplay sidebar` with no objective clears the sidebar slot.
- `list`, `belowName`, and one `sidebar.team.<color>` slot parse onto the matching `ScoreboardDisplaySlot`.
- An unknown slot does not parse, or returns `commands.scoreboard.objectives.setdisplay.invalidSlot`.
- Success feedback uses `commands.scoreboard.objectives.setdisplay.successSet` and `successCleared`.

## Verification
