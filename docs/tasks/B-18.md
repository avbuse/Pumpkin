## Goal

Map each chunk section to a region id. An entity's region is the region of the section that contains it. The map is the structure B-19 will tick. With the default single-region switch, every section has the same id.

## Files and crates

- `crates/pumpkin-core/src/world/ (region map module)`

## Acceptance criteria

- Two coordinates in the same region share an id.
- Two coordinates a region apart do not, when the switch is in multi-region mode.
- Default mode returns one id for the whole world.

## Verification

Unit test of the map.

## Out of scope

- Ticking. B-19.
