## Goal

When enabled, if MSPT stays above an admin limit, reduce view and simulation distance inside admin bounds, and raise them again after MSPT recovers. The default is off, and off means distances never move.

## Files and crates

- `crates/pumpkin-core/src/server/ticker.rs`
- `config`

## Acceptance criteria

- With the flag off, view distance is unchanged after a slow tick.
- With the flag on, a forced slow window reduces distance and a calm window restores it.
- Distances never leave the configured bounds.

## Verification

A unit test with scripted tick times.

## Out of scope

- Changing the default view distance.
