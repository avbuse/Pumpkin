## Goal

Opening a 26.3 world is not enough if walking to the edge crashes or writes a chunk the client rejects. Load a cached vanilla world and generate one neighbouring chunk that was not in the save. The client must receive that chunk. Record the block mismatch against a vanilla generation of the same seed if the harness can produce it. A mismatch does not fail the task when it is within the A-45 baseline. A crash or an empty chunk does.

## Files and crates

- `crates/pumpkin-world/src/chunk_system/`
- `tools/pumpkin-compat/ (a scenario, after A-02 if you use a downloaded world)`

## Acceptance criteria

- A chunk adjacent to imported terrain is sent to the client.
- The world still saves.
- The mismatch against vanilla, if measured, is recorded next to the baseline.

## Verification

Harness scenario with PUMPKIN_COMPAT_VANILLA left as the milestone check. The new scenario is Pumpkin-only if vanilla generation of that chunk is too slow for CI. Say which one ran.

## Out of scope

- Closing the worldgen gap. A-46 is one feature, not this task.
