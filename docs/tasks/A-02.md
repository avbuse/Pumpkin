## Goal

Imported-world checks need a real 26.3 world without committing Mojang files. Extend the harness downloader so a test can obtain a small vanilla-generated world into target/compat-cache or PUMPKIN_COMPAT_CACHE, then point Pumpkin at that directory. The jar and the world stay in the cache. eula.txt is written only inside the temporary server directory.

## Files and crates

- `tools/pumpkin-compat/src/vanilla.rs`
- `tools/pumpkin-compat/src/pumpkin_proc.rs`

## Acceptance criteria

- A test can request a cached 26.3 world and receive a path under the cache directory.
- Nothing under assets/ or the git tree gains a jar, region file, or level.dat from Mojang.
- The download host list stays limited to the piston and launcher hosts the harness already allows.

## Verification

Unit-test the cache path and the host allow-list with a fixture URL. Do not commit the downloaded world.

## Out of scope

- Changing Pumpkin's data-version check. That is A-04.
- Generating new chunks. That is A-47.

## Rules

Read `docs/tasks/README.md` before starting. One task on one branch. Commit with `git commit -s`. Push only to `avbuse/Pumpkin`. Do not open a pull request and do not push to `Pumpkin-MC/Pumpkin`. Do not commit a Mojang jar, region file, or decompiled source, and do not paste Java into the repo. Class names in the research notes are pointers. Reimplement from the description.
