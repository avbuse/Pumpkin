## Goal

Datapacks have no predicate loader. Load the predicate files the vanilla data pack already ships, and evaluate the subset that story advancements and one loot table need: location, item, and entity-property checks that those JSON files actually reference. Unknown predicate types fail the load with a log line, they do not panic.

## Files and crates

- `crates/pumpkin-core/src/data/datapack/mod.rs`
- `a new predicate module beside it`

## Acceptance criteria

- A predicate JSON from assets/ that uses only the supported checks evaluates true and false on a constructed context.
- An unknown type is reported and skipped.
- Recipes and loot that already load still load.

## Verification

A unit test with one predicate JSON taken from assets/, not copied into the test by retyping the whole file if include works.

## Out of scope

- The full predicate language.
- Worldgen JSON. A-46 owns one feature family.
