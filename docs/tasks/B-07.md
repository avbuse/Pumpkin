## Goal

When several players are sent the same chunk at the same compression settings, reuse the already compressed packet bytes. A chunk that changes drops the cache entry. Players with different view settings still get a correct packet.

## Files and crates

- `crates/pumpkin-core/src/net/java/ (chunk sender)`

## Acceptance criteria

- Two viewers of an unchanged chunk share one compressed buffer.
- A block change causes the next send to rebuild it.
- The client still receives a chunk that decodes.

## Verification

Harness: two clients, one chunk, a block change between sends. A unit test of the cache key is enough if a second client is hard.

## Out of scope

- The compression library. B-06.
