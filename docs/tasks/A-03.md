## Goal

Survival scenarios need to give items, open a container, and click a slot. Add helpers on the harness client for a console command, a container click, and a short wait until a window or slot update arrives. Use the existing pumpkin-protocol play packets.

## Files and crates

- `tools/pumpkin-compat/src/client.rs`
- `tools/pumpkin-compat/src/scenario.rs`

## Acceptance criteria

- A scenario can run give and setblock through the server console and observe the resulting slot or block update.
- Helpers return a timeout error when the expected packet does not arrive. They do not panic.

## Verification

A focused harness test that gives one stone and checks the slot. pumpkin_smoke still passes.

## Out of scope

- Item behaviour itself. Tasks A-13 onward own that.
