## Goal

Chunk NBT gained or renamed fields between data versions 4903 and 5023. Inspect the 26.3 server jar locally, or the minecraft.wiki chunk format page, and write a short note that lists each field a loader must add, drop, or reinterpret. Name the vanilla class as a pointer. Describe the field in your own words. This note is the input for A-48.

## Files and crates

- `docs/compat/CHUNK_FORMAT_5023.md`

## Acceptance criteria

- The note lists only fields that differ from what Pumpkin already reads.
- Each field says whether it is added, removed, or reinterpreted, and which chunk section it lives in.
- The note contains no Java source and no pasted NBT dumps from Mojang.
- If nothing relevant changed, the note says that, with the classes that were checked.

## Verification

The document itself. No server boot.

## Out of scope

- Implementing the loader. That is A-48.
- A general DataFixer.
- Committing the server jar or a decompiled tree.

## Rules

Cut `core/A-08-chunk-format-notes` from `core-functionality`. Read `docs/tasks/README.md` and `docs/BRANCHING.md`. Merge the task branch back into `core-functionality` only. Commit with `git commit -s`. Push only to `avbuse/Pumpkin`. Do not open a pull request and do not push to `Pumpkin-MC/Pumpkin`. Do not commit a Mojang jar, region file, or decompiled source, and do not paste Java into the repo. Class names in the research notes are pointers. Reimplement from the description. Clippy denies `unwrap`, `expect`, `panic`, and printing to stdout.
