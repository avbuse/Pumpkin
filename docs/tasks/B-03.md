## Goal

get_entities_at_box, get_nearby_entities, get_players_at_box, and get_nearby_players scan every entity in the world. Replace the scan with a section index: an entity is listed in the section that contains its bounding box. Queries return the same set as the linear scan. Keep the linear scan behind a test-only comparison until the counts match on a fixture.

## Files and crates

- `crates/pumpkin-core/src/world/mod.rs`
- `a new spatial module next to it if the file is already too large`

## Acceptance criteria

- A fixture with entities in two distant sections returns only the near ones.
- Moving an entity from one section to another updates the index.
- Removing an entity drops it from the index.
- Callers of get_entities_at_box compile without a behaviour change.

## Verification

A unit or gametest that compares index results with a linear scan on a fixed set.
