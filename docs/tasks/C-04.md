## Goal

An operator can mute a player and can set a chat delay. Flag off means chat is unchanged. A muted player still receives chat.

## Files and crates

- `a mute command file`
- `the chat handler that already broadcasts messages`

## Acceptance criteria

- Flag off: two chat messages in one second both broadcast.
- Flag on: a muted player's message is dropped.
- Slowmode drops a second message inside the window.

## Verification

Harness chat packets.

- Word filters.
