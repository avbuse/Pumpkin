## Goal

Region chunks can be stored with compression id 127, which is a custom scheme named in the chunk header. Pumpkin currently returns UnknownCompression and the chunk fails to load. Either implement the scheme vanilla uses for that id, or return a named error that says the chunk was skipped and why. A normal gzip, zlib, lz4, or uncompressed chunk must keep loading.

## Files and crates

- `crates/pumpkin-world/src/chunk/format/anvil.rs`

## Acceptance criteria

- Ids already supported still decode.
- Id 127 no longer surfaces as a bare unknown-compression failure with no context.
- A corrupt length inside a 127 chunk does not panic.

## Verification

Unit tests with hand-built chunk bytes. Do not commit region files from a vanilla world.
