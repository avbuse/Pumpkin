## Goal

On join, if voice is enabled, answer the setup plugin channel described in the D-01 note with a per-session secret and the UDP endpoint. If voice is disabled, ignore the channel. Do not open the UDP socket in this task. A client that never sends the channel plays normally.

## Files and crates

- `crates/pumpkin-core/src/net/java/ (plugin messages)`
- `config`

## Acceptance criteria

- Flag off: no voice payload is sent, and pumpkin_smoke passes.
- Flag on: a client that sends the setup channel receives a secret and an endpoint.
- The secret is not written to the log.

## Verification

A harness custom payload. The harness does not speak audio.

## Out of scope

- Opus decode.
- Proximity. D-04.
