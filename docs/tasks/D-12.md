## Goal

When session recording is enabled, record one player's positions and the block changes already in the log into a documented folder layout under the server directory. Chat, containers, and voice stay out unless their flags are on, and those flags default off. The format note lives in docs/research/audit-replay.md. A size cap stops the recording.

## Files and crates

- `a recording module`
- `docs/research/audit-replay.md`

## Acceptance criteria

- Flag off: no recording directory.
- Flag on: a movement and a block change are both present.
- Chat text is absent by default.
- The file stops growing after the cap.

## Verification

A unit test that reads the written folder.
