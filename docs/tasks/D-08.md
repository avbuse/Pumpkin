## Goal

Requests without a configured token receive 401. The token is a config value and is not logged. Localhost-only bind remains the default even with a token.

## Files and crates

- `the map HTTP module`
- `config`

## Acceptance criteria

- No token header returns 401.
- The right token returns the tile.
- The token does not appear in logs.

## Verification

HTTP requests in a test.

## Out of scope

- User accounts.
