## Goal

Bind the UDP port from config when voice is enabled. Accept a packet only if it carries a secret issued by D-02. Forward the encrypted payload to other authenticated sockets in a later task. This task authenticates and drops. Decode must not run on the game tick. A bind failure logs one line and leaves the Minecraft port up.

## Files and crates

- `a new voice module under crates/pumpkin-core/src/`
- `config`

## Acceptance criteria

- A packet with a valid secret is accepted.
- A packet with a bad secret is dropped.
- The game tick does not call into the UDP read.
- Flag off binds nothing.

## Verification

A unit test of the secret check. Do not commit audio.

## Out of scope

- Proximity fanout. D-04.
- Recording audio.
